The toolkit

Useful tools, minus the clutter.

A practical set of everyday utilities for developers, brought together in one desktop application.

⌘

JSON tools

Format, validate, and minify JSON when APIs return the usual wall of braces.

⇄

Encoding utilities

Encode and decode Base64, Base64URL, URL strings, and HTML entities.

⌕

Regex tester

Try regular expressions with common flags against sample text.

≠

Text comparison

Compare text and inspect differences without opening another website.

Identifiers & time

Generate UUIDs and convert Unix timestamps to readable UTC dates.

◈

File & color tools

Inspect file details, calculate hashes, parse URLs, and convert color formats.

Documentation

Get started in a few steps.

The full setup guide lives in COMMANDS.md in the source repository. These are the essentials.

01 · Requirements

  • Python 3 installed and available from your terminal.
  • Download and extract the source ZIP.
  • Use Windows instructions below for desktop shortcut creation.

02 · Open the project

Extract the ZIP, open a terminal in the extracted project folder, and read COMMANDS.md for the exact launch command and any dependencies.

# Open COMMANDS.md first
# Follow the commands for your platform

03 · Windows desktop shortcut

The project includes a shortcut setup script. Run it from the extracted project folder using Python, as described in COMMANDS.md. It creates a desktop shortcut without requiring an EXE.

04 · Testing

The project includes a test suite. Follow the test command in COMMANDS.md to verify your local setup.

Tip: Keep the application folder in a permanent location before creating a shortcut, so the shortcut doesn't point to a folder you later move.

Help center

Frequently asked questions

Where are the commands?

Open COMMANDS.md in the downloaded project. It contains setup, launch, test, and Windows shortcut instructions.

Do I need Git?

No. You can download the ZIP from the release page using your browser.

Is Lioma Open Tools free?

Yes. The project is released under the MIT License. Read the license in the source repository for the terms.

How do I report a bug?

Open the repository on GitHub and create an issue with the steps to reproduce the problem and any relevant error message.

Does the app require an account?

No account is required to use the desktop application. The project's utilities are designed to run locally.

Can I contribute?

Yes. See the repository's CONTRIBUTING.md guide and open a pull request or issue on GitHub.

Open source

Built to be useful. Open to improvement.

Contributions, bug reports, and practical feature requests are welcome. Read the project guidelines and help make the toolbox better for everyone.
